Ideas

  1. Sidebar instead of top tabsSource list on the left (Meeting baru, ongoing meeting, recent meetings grouped by Hari ini / Minggu ini), like Notes, Mail and Finder.
  2. Toolbar inside the title barHide the default title bar; traffic lights, meeting title, timer, levels and Akhiri share one 52 px toolbar (Tauri titleBarStyle: "Overlay").
  3. Translucent sidebarNative macOS vibrancy behind the sidebar (window-vibrancy crate); Mica on Windows 11.
  4. System accent colourUse the colour the user picked in macOS (CSS AccentColor) instead of a hard-coded indigo; red only for recording.
  5. No floating cardsContent goes edge to edge, separated by 1 px hairlines. Cards only where macOS uses them (grouped settings).
  6. System font, system sizesSF Pro / Segoe UI at 13 px, 11 px for secondary text; no spaced-out capitals, no oversized headings.
  7. Transcript as the document, AI as inspectorMain area reads like a notes document; AI help sits in a hideable right panel (⌘⌥I).
  8. Status barThin bottom bar for transcription engine, register, auto-assist and context files instead of chips and badges.
  9. Grouped forms like System SettingsMeeting setup and preferences as label-left / control-right rows with pop-up buttons and switches.
  10. Separate Preferences window⌘, opens a classic preferences window with an icon toolbar (Umum, AI, Transkripsi, Bahasa, Siluman, Privasi).
  11. Mail-style historyList in the middle, notes on the right, search field on top of the list, Share menu for Word / Markdown / WhatsApp.
  12. Real menu barFile › Meeting baru ⌘N, Meeting › Bantu jawab ⌘⇧J, View › Tampilkan inspector ⌘⌥I, plus right-click menus on meetings.
  13. Menu-bar extraA small icon in the macOS menu bar (Windows tray) with Start / Stop, Stealth on/off and the hotkeys.
  14. HUD overlayOverlay as a dark translucent HUD panel with no buttons, only text and shortcuts.
  15. Native controlsSmall 6 px radius, pop-up buttons, segmented controls and switches that match the OS; default button = accent.
  16. Quiet empty statesPlain grey sentences ("Belum ada meeting"), no illustrations or emoji.
  17. Remember window stateRestore window size, sidebar width and inspector visibility on next launch (tauri-plugin-window-state).
  18. Windows lookSame layout with Segoe UI Variable, Mica and Windows accent colour, caption buttons on the right.
