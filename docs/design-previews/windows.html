Ideas for Windows

  1. Mica backdropReal Mica behind the title bar and navigation on Windows 11 (window-vibrancy crate, apply_mica); plain grey on Windows 10.
  2. Custom title bar, native caption buttonsTauri decorations: false with a drag region, app icon and title on the left, a search box in the middle, and WinUI-style minimise / maximise / close on the right (keeps Snap Layouts on hover via the maximise button).
  3. NavigationViewLeft navigation with a hamburger to collapse it, 16 px line icons, accent pill on the selected item; Siluman and Pengaturan pinned at the bottom.
  4. Settings as a pageWindows puts settings inside the app (Ctrl+,), with Settings-app style rows: icon, title, description, control on the right.
  5. Windows accent colourUse the user's accent from Personalisation (CSS AccentColor; Tauri can also read it); default blue #005FB8 / #60CDFF.
  6. Segoe UI Variable + Fluent type rampBody 14 px, caption 12 px, subtitle 20 px, title 28 px; no letter-spaced capitals.
  7. Fluent controls4 px radius buttons with a subtle bottom edge, accent button for the main action, ComboBox, ToggleSwitch, TextBox with an accent underline on focus.
  8. CommandBar and InfoBarActions (Akhiri, Asisten, Bagikan) as icon + label buttons in a command bar; status as an InfoBar instead of a Mac-style status bar.
  9. Outlook-style panesTranscript as the main pane with a reading pane for the assistant; history as list + detail.
  10. Tray iconNotification-area icon with Start / Stop meeting, Siluman on/off and the shortcuts; closing the window can minimise to tray.
  11. Ctrl shortcutsCtrl+N meeting baru, Ctrl+Shift+J bantu jawab, Ctrl+Shift+H sembunyikan, Ctrl+, pengaturan, Ctrl+F cari.
  12. Taskbar integrationTaskbar progress while notulen is being written and a red overlay badge while recording.
  13. Toast notifications“Notulen siap” and “Pertanyaan terdeteksi” as Windows toasts that open the meeting when clicked.
  14. Acrylic overlay flyoutSmall translucent always-on-top panel, hidden from screen capture (WDA_EXCLUDEFROMCAPTURE).
  15. InstallerNSIS setup .exe (per-user install, no admin) as the main download; .msi optional for managed PCs.
  16. Unsigned buildWithout code signing, SmartScreen shows “Windows protected your PC” → More info → Run anyway. Fine for personal use.
  17. Respect Windows settingsFollow light/dark, accent, text scaling and “Show animations” (reduced motion) from Windows Settings.
  18. Remember window stateRestore size, position, navigation collapsed state and pane width on next launch.
